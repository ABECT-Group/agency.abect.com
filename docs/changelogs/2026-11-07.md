## Запит 1 — Повний аудит проекту

**Запит розробника:** проаналізувати проект: git і гілки, деплой на VPS, скрипти `backup.sh` / `restart.sh`, сміття, md-документи, ченджлоги.

### Результати
- **Git:** репозиторієм є лише `frontend/` → `github.com/forze-dev/ABECT`, 47 комітів, гілка `main` чиста й синхронізована. Гілки `claude/session-inquiry-01DCVQ…` (локальна + remote) і `origin/vercel/react-server-components-cve-…` уже злиті, їх можна видалити. Тегів і CI немає.
- **Деплой:** ручний `git pull` + `docker compose up --build` на VPS, nginx → `127.0.0.1:3333`, Mongo в мережі `abect-shared`.
- **Критичне:** порт 3333 доступний з інтернету (ISS-002), CVE в залежностях (ISS-004).
- **Серйозне:** `NEXT_PUBLIC_*` не потрапляють у білд (ISS-003), sitemap без динамічних сторінок (ISS-007), бекапи без `media/` і без копії поза сервером (ISS-006), зайва мережа `mongodb-net` (ISS-005), простій під час деплою (ISS-008).
- **Документація:** застаріла, дублювалась (два SEO-плани з однаковим змістом, ТЗ на вже реалізоване), містила неправильні інструкції (`pm2`, `.env.local`).
- **Ченджлог:** не вівся.

Перевірки на живому сайті (лише GET): `:3333` → 200, `/seo/og.jpg` → 404, `/sitemap.xml` → 16 статичних URL, заголовок `Link hreflang="ua"`.
